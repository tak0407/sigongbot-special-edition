# 온라인 회고 투표 완료 후 자동 확정

## 합의한 동작

공지 채널에 게시된 기존 온라인 회고 투표 메시지를 갱신한다. 조별 전원이 응답하면
“모든 조원이 투표를 마쳤어요. 1시간 뒤 모임 시간이 확정됩니다.”와 확정 예정 시각을
표시한다. 조마다 독립적으로 1시간 후 확정 일시와 해당 시간 참석 예정 명단을 표시한다.
다른 조가 투표 중이면 같은 메시지에서 투표를 계속 받는다.

## 구현 선택

- 기존 SQLite와 60초 스케줄러를 사용한다. 메모리 타이머는 재시작 때 사라지므로 사용하지 않는다.
- 별도 확정 메시지를 추가하는 대신 기존 공지 메시지를 조별 상태와 모임 안내로 갱신한다.
- 기존 수동 확정의 Calendar/Meet 생성과 멱등 이벤트 ID를 재사용한다.
- 구현자 판단: 최다 득표 시간으로 정하고 동률이면 이른 시간을 고른다. 기존 관리자 화면의 기본 선택과 같다.
- 구현자 판단: '이번엔 어려워요'도 응답에 포함한다. 전원 응답 후 수정은 가능하지만 최초 완료 시각은 미루지 않는다.
- 구현자 판단: 팀 구성이 바뀌어 미응답자가 생기면 타이머를 해제하고 다시 전원 응답했을 때 시작한다.
- 구현자 판단: 이미 모두 응답한 기존 투표는 새 기능이 처음 감지한 시각부터 1시간을 준다.
- 구현자 판단: 모두 불참하거나 선택된 시간이 이미 지났으면 잘못된 모임을 만들지 않고 운영자 확인 상태로 남긴다.
- 수동 확정·취소를 존중한다. 확정 처리 중이거나 확정된 투표의 추가 응답을 막는다.
- Google 오류 시 확정 완료로 표시하지 않는다. 재시도 간격을 두고, Slack 실패 시 Google 이벤트를 중복 생성하지 않는다.

## 제약과 검증

새 스키마는 migration 21에만 추가한다. 운영 DB와 실제 Slack·Google은 검증에 사용하지 않는다.
임시 SQLite와 외부 API 대역으로 1시간 경계, 재시작 복구, 조별 독립 동작, 응답 수정,
전원 불참, 확정 후 응답 차단, Google/Slack 실패와 중복 방지를 검증한다.
최초 요청은 구현 범위였으며, 2026-11-09 추가 요청으로 검증 후 운영 배포까지 승인됐다.
Meet 입장 설정 경고는 확정 정보와 함께 저장하고 관리자 화면과 운영자 알림에 남긴다.
알림 실패는 재시도하며 Google 이벤트를 다시 만들지 않는다.
